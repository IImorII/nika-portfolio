# Редактор контуров банок

Запуск из корня проекта: `npm run jar-editor`. Откройте http://127.0.0.1:5174.
Нужен Node.js 22 или новее. Установка дополнительных пакетов не требуется.

Редактор показывает все банки со слоями без поворота и масштаба из настроек.
Красный контур — граница полёта частиц. Пунктир показывает исходный контур только для сравнения: он не ограничивает редактируемую зону.

- Перетаскивайте вершины мышью или пальцем. Стрелки двигают выбранную вершину на 0,1%, Shift + стрелки — на 1%.
- Поля X/Y задают точные координаты выбранной вершины в процентах изображения.
- Двойной щелчок рядом с линией добавляет вершину. «Удалить точку» или Delete удаляет выбранную вершину; минимум — три.
- «Открыть крупно» увеличивает рабочую область. «Отменить»/«Вернуть» меняют историю правок, «Сбросить правки» возвращает последний сохранённый контур.
- **Save** записывает только `particleZone` в `public/assets/<категория>/jar/settings.json`. Положение, размеры и локальные точки вычисляются из отредактированного полигона. Остальные настройки сохраняются.

Самопересечения и вырожденные контуры не сохраняются. Если файл изменили вне редактора, запись останавливается, чтобы сохранить внешние изменения; обновите страницу.
После сохранения выполните `npm run build`, чтобы изменения вошли в приложение. При `npm run dev` достаточно дождаться пересборки и обновить страницу.

Этот каталог находится вне `public` и не импортируется основным приложением. GitHub Pages публикует только `dist`, поэтому редактор и сервер записи не деплоятся.
Сервер слушает только `127.0.0.1`. Для другого локального порта задайте `JAR_EDITOR_PORT` перед запуском.
